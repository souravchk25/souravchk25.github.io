How much can a linear-attention model remember, and how do we make it remember more?

Softmax attention keeps every key and value it has seen, so its memory grows with the context. Linear attention folds them all into one state of fixed size, $S_t = S_{t-1} + \psi(k_t)\,v_t^\top$, and recall degrades once too many key–value pairs share it. Treating recall as packing unit vectors on a sphere shows where the limit comes from. Feature maps built on self-dual cones keep attention weights nonnegative, and the rank-one PSD map $\psi(u) = uu^\top$ squares the overlap between keys: in an idealized analysis, the number of keys it can tell apart grows from about $2p$ to about $p^2$ with the same number of projection parameters.
