Can each agent decide well using only what its neighbors are doing?

With $n$ agents the joint state and action spaces grow exponentially, so nobody can plan over all of it. In power grids, traffic and fleets, though, an agent's choices mostly affect the agents near it. If that influence fades fast enough with distance, each agent can plan with only its $\kappa$-hop neighborhood. We show that whether it fades depends on the policy as well as on the environment.

The framework separates how strongly the environment couples agents from how smooth the policy is. With Adam Wierman, we are now asking what communication delay between agents does to all this.
